Q1: Explain What Happens Between Typing a URL and Seeing the Page?
Ans:When we type a URL (Uniform Resource Locator) into a web browser and press Enter, several steps take place before the webpage appears on the screen. First, the browser checks the URL and identifies the website we want to visit. Next, the browser uses DNS (Domain Name System) to convert the domain name into an IP address that identifies the server hosting the website. The browser then establishes a connection with the server using TCP and, for HTTPS websites, performs a TLS handshake to create a secure connection. After that, the browser sends an HTTP request to the server asking for the webpage. The server processes the request and sends an HTTP response containing HTML, CSS, JavaScript, images, and other required resources. The browser then parses the HTML to create the DOM (Document Object Model), processes CSS to calculate the styles, and executes JavaScript to make the webpage interactive. It also downloads additional resources when needed. Finally, the browser calculates the layout, paints the elements, and displays the webpage on the screen. This entire process happens very quickly, allowing us to access websites within seconds.
